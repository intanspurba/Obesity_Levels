# Obesity Levels Classification Using Machine Learning

## Project Overview
This project explores obesity-level classification
using machine learning based on eating habits,
physical activity, and individual characteristics.

## Dataset
- Source: [Kaggle](https://www.kaggle.com/datasets/fatemehmehrparvar/obesity-levels)
- Records: 2,111
- Attributes: 17
- Target: NObeyesdad (7 categories)

## Workflow
1. Data Collection and Loading
2. Data Cleaning and Transformation
3. Exploratory Data Analysis (EDA)
4. Data Preprocessing
5. Data Splitting
6. Model Training and Evaluation

## Models
- K-Nearest Neighbors (KNN)
- Logistic Regression
- Gradient Boosting Classifier

## Results
Gradient Boosting Classifier achieved:
- Accuracy: 94.5%
- Macro F1-Score: 94.4%

Results are based on this project's test split.

## Technologies
Python, Pandas, NumPy, Matplotlib,
Seaborn, Scikit-learn, Jupyter Notebook
